# Spec execution details

Details that keep a spec usable while sail works.

- Give a blocker section a heading in the spec's language that names the block,
  and write the context needed to resume.
- Do not label verification-method lines; the count of conditions stays separate
  from the count of checks.
- A question from a cold executor is a spec defect. Answer it, write the answer
  into design, out-of-scope, or acceptance criteria, then let it continue.
