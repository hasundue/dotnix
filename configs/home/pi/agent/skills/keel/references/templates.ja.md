# テンプレート（日本語）

タスクごとにワークツリーのルートへ `SPEC.md` を 1 つ置く．見出しが構造であり，その下の文章はそうではない．短く保つ．読み返されない spec はゲートにならない．

日本語のセッションではドラフトを `SPEC.ja.md` として書く．承認時の翻訳，独立したチェック，昇格の手順は `spec-lifecycle.md` にある．ドラフトと翻訳候補はコミットしない．

フロントマターのキーは英語のままにする．`status` は `draft` / `agreed` / `blocked` / `stale` のいずれかで，`stale` は承認済みの spec の作業を続けないことを示す．破棄したドラフトはコミットせず削除し，`stale` にはしない．`session_lang` は会話の言語コード．`## ブロッカー` は `status: blocked` のときだけ置く．値のない項目は空にしておき，この説明を spec に写さない．

## テンプレート

```markdown
---
status: draft
session_lang: ja
---

# <短いタイトル>

## 問題

<変更が必要な理由を 2〜4 行で書く．解決策は書かない．>

## 設計

<実装を縛る決定を 1 行ずつ，理由とともに書く．決定が依存するパスは，その行に書く．決定やログのセクションは作らない．>

## 対象外

- <明示的に作らないもの>

## 受け入れ条件

<条件は素の `-` で書き，その検証方法を 2 空白で字下げした `- [ ]` としてぶら下げる．コマンド，または期待する観察結果を添えた手作業の手順を書く．ユーザーの判断で終わる条件は何を決めるかだけを述べ，返答の形式は指定しない．>

- <観測できる結果>
  - [ ] <コマンド，または期待する観察結果を添えた手順>

## 停止条件

<タスク固有の制限と条件だけを書く．ない場合はこのセクションを省略する．全タスクに共通する停止条件は sail スキルに置く．>
```

`status: blocked` のときだけ，以下のセクションを追加する．

```markdown
## ブロッカー

<再開に必要なコンテキスト．たとえば試したこと，起きたこと，考えられる原因，選べる選択肢．>
```

status が `blocked` でなくなったら，そのコンテキストをコミット本文に移してセクションを削除する．

## 言語

見出しの英語対応と翻訳の手順は `spec-lifecycle.md` に置く．日本語のドラフトを書くのに英語テンプレートを読む必要はない．承認後は本文も英語になり，ブロッカーや範囲の変更も英語で書く．

## 条件とチェックの規則

- `- [ ]` は条件ではなく，条件を確かめる方法．
- 実行したら `- [x] <方法> -- <コマンドと結果>` と記録する．失敗したものや実行できなかったものは未チェックのまま `unmet: <理由>` を添える．
- `## 対象外` は素の `-` を使う．`[ ]` は検証方法だけに意味を持たせる．
- チェックを入れることは条件の再交渉ではない．条件の文言を変えるには新しい承認が必要．
- 検証方法にラベルは付けない．条件の数と検証の数を分けて数えられるようにする．

## 簡略例

```markdown
---
status: draft
session_lang: ja
---

# アイドルでセッションを切る

## 問題

ログイン後 24 時間で，作業中でもセッションが切れる．セッションは時計ではなく，利用者が操作を止めたときに切れるべき．

## 設計

- 認証済みリクエストごとに `expiresAt` を進め，絶対上限は変えない -- 上限はコンプライアンス要件のため．
- `src/auth/session.ts` は現在ログイン時に `expiresAt = issuedAt + 24h` を設定する．`tests/auth/session.test.ts` は 24 時間を前提にしているので，アイドルと絶対期限を分けて検証するよう書き換える．

## 対象外

- 永続ログイン，リフレッシュトークン，ロール別の期限
- 既存セッションの移行（旧ルールのまま期限切れになる）

## 受け入れ条件

- 最後のリクエストから 31 分後のリクエストが 401 で拒否される
  - [ ] `pnpm test tests/auth/session.test.ts -t idle`
- 最後のリクエストから 29 分後のリクエストが成功し，時計が進む
  - [ ] 同じテストファイルで `-t active`
- 24 時間の絶対上限が残る
  - [ ] 同じテストファイルで `-t absolute`

## 停止条件

- `src/billing/` に触れる必要が生じたら停止する
```
